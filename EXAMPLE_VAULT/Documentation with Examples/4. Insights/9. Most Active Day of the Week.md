Which weekday you log most often across the year.

```
{
  name: "The most active day of the week",
  calculate: ({ yearEntries }) => {
    const dayCounts = {};

    yearEntries.forEach((entry) => {
      const day = new Date(entry.date).toLocaleDateString("en-US", { weekday: "long" });
      dayCounts[day] = (dayCounts[day] || 0) + 1;
    });

    return Object.entries(dayCounts).reduce(
      (maxDay, [day, count]) => (count > maxDay.count ? { day, count } : maxDay),
      { day: "", count: 0 },
    ).day;
  },
}
```
