The date of your single best day this year.

```
{
  name: "Day with the Highest Value",
  calculate: ({ yearEntries }) => {
    if (yearEntries.length === 0) return "No data";

    return yearEntries.reduce((max, entry) =>
      (entry.value || 0) > (max.value || 0) ? entry : max,
    ).date;
  },
}
```
