How many days fall into each intensity level, as one line.

```
{
  name: "Intensity Distribution",
  calculate: ({ yearEntries }) => {
    const distribution = {};

    yearEntries.forEach((entry) => {
      const intensity = Number(entry.intensity) || 0;
      distribution[intensity] = (distribution[intensity] || 0) + 1;
    });

    return Object.entries(distribution)
      .map(([intensity, count]) => `Intensity ${intensity}: ${count}`)
      .join(", ");
  },
}
```
