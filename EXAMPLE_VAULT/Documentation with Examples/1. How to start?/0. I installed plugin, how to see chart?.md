The fastest way — and the recommended one — is the built-in modal. You don't write any YAML or JavaScript.

1. Open any note.
2. Run **Insert Heatmap Tracker** from the command palette, or click the Heatmap Tracker icon in the left ribbon.
3. Pick the property you want to track (the dropdown lists the frontmatter keys already in your vault), optionally narrow it to a folder, and give it a title.
4. Watch the preview on the right — it tells you how many notes currently match. If it says none, the property name or folder is wrong.
5. Click **Insert Heatmap**.

Changed your mind? Hover the heatmap and click the pencil button in its corner: the same form reopens with that heatmap's settings and rewrites the codeblock when you save.

Everything else on this page is optional: it shows what the modal writes, in case you prefer typing it yourself.

```heatmap-tracker
property: steps
path: daily notes
```

If you need computed values or data that doesn't live in frontmatter, the `dataviewjs` escape hatch is still there:

```dataviewjs

const trackerData = {
    year: 2025,
    entries: [],
    heatmapTitle: "Steps Example"
}

const PATH_TO_FOLDER = "daily notes";
const PARAMETER_NAME = "steps";
 
for(let page of dv.pages(`"${PATH_TO_FOLDER}"`).where(p=>p[PARAMETER_NAME])){
    trackerData.entries.push({
        date: page.file.name,
        filePath: page.file.path,
        intensity: page[PARAMETER_NAME]
    })  
}

trackerData.basePath = PATH_TO_FOLDER;

renderHeatmapTracker(this.container, trackerData)

```
