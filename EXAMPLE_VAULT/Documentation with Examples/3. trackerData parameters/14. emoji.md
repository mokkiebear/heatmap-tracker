# emoji

> 📖 Full parameter reference: [README → `Emoji habit tracking`](https://github.com/mokkiebear/heatmap-tracker#emoji-habit-tracking)

An **entry** property. Draws a short glyph inside that day's box while the box
keeps its palette color — so a yes/no habit reads at a glance instead of as a
gradient you have to decode.

## Example

```dataviewjs
const trackerData = {
    entries: [
        {
            date: "2025-01-01",
            intensity: 1,
            emoji: "🏃",
            content: "5km, felt good"
        },
        {
            date: "2025-01-02",
            intensity: 1,
            emoji: "📖"
        },
        {
            date: "2025-01-03",
            intensity: 1,
            emoji: "🧘"
        },
        {
            date: "2025-01-06",
            intensity: 1,
            emoji: "🏃"
        },
        {
            date: "2025-01-07",
            intensity: 1,
            emoji: "📖"
        }
    ],
    heatmapTitle: "Emoji Example",
    colorScheme: {
        customColors: ["#c6e48b", "#7bc96f", "#239a3b"]
    }
}

renderHeatmapTracker(this.container, trackerData);
```

## Tracking two habits on one heatmap

The common reason to want this: you do one of two things each day, and you want
a single unbroken streak rather than two sparse heatmaps.

```dataviewjs
const trackerData = {
    entries: [],
    heatmapTitle: "Movement",
    colorScheme: { customColors: ["#7bc96f"] },
}

for (const page of dv.pages('"Daily"').where(p => p.run || p.yoga)) {
    trackerData.entries.push({
        date: page.file.name,
        intensity: 1,
        emoji: page.run ? "🏃" : "🧘",
        filePath: page.file.path,
    })
}

renderHeatmapTracker(this.container, trackerData);
```

## `emoji` vs `content`

They are different things and can be used together:

| | `emoji` | `content` |
|---|---|---|
| Drawn | Centered, sized to fill the box | Inline, inherits link styling |
| Length | Max 8 characters (validation rejects more) | Any length, clipped by the box |
| Accepts | Text only | Text or an `HTMLElement` (e.g. `dv.span(...)`) |
| Screen readers | Skipped — the box's own label says the date and value | Read out |
| Report export | Not included | Becomes the day's body text |

So: `emoji` for the marker, `content` for what actually happened that day. In
the first example above, January 1st has both — the box shows 🏃 and the
exported report says "5km, felt good".

## Notes

- **Any short text works**, not only emoji: `"✓"`, `"x"`, `"1"` are all valid.
  Monochrome glyphs get a subtle outline so they stay readable on dark palette
  colors.
- **Two entries on the same day:** only one glyph fits, so the first `emoji`
  set for that day is the one drawn.
- Works in both the default grid and `layout: "monthly"`.
