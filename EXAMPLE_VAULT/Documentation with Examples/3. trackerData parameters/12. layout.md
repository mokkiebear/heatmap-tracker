# layout

> 📖 Full parameter reference: [README → `layout`](https://github.com/mokkiebear/heatmap-tracker#layout)

## Example

```heatmap-tracker
heatmapTitle: Monthly View
layout: monthly
property: exercise
```

## Combined with monthsToShow

```heatmap-tracker
heatmapTitle: Last 3 Months
layout: monthly
monthsToShow: 3
property: exercise
```

## Single month (calendar)

Weekdays as columns, weeks as rows. Starts on the current month; the header
arrows page through months.

```heatmap-tracker
heatmapTitle: This Month
layout: month
property: exercise
```

## Single week

One row of seven days, starting on the current week.

```heatmap-tracker
heatmapTitle: This Week
layout: week
property: exercise
```

## Pinned to a fixed period

Giving a date range replaces the current-period default and hides the arrows.

```heatmap-tracker
heatmapTitle: March 2024
layout: month
startDate: 2024-03-01
endDate: 2024-03-31
property: exercise
```
