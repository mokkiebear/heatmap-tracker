# intensityConfig

> 📖 Full parameter reference: [README → `intensityConfig`](https://github.com/mokkiebear/heatmap-tracker#intensityconfig)

## Example

```dataviewjs
const trackerData = {
    entries: [
        { date: "2025-01-01", intensity: 10 },
        { date: "2025-01-02", intensity: 1 },
    ],
    intensityConfig: {
        scaleStart: 1,
        scaleEnd: 10,
        excludeFalsy: true,
        defaultIntensity: 5,
        showOutOfRange: true
    },
    heatmapTitle: "Heatmap with intensityConfig",
}

renderHeatmapTracker(this.container, trackerData);
```

## aggregation: average

A day whose value comes from several numbers is scored on their sum by default.
That's right for totals, but wrong for ratings: with two readings a day, a day
you only logged once scores half of what it should.

Both heatmaps below hold the same readings — a 1–10 rating, twice a day, where
Jan 3 only got a morning entry. Summed, that day looks like a `4`. Averaged, it
is the `8` it actually was: only the readings that exist count towards the
divisor.

```dataviewjs
const entries = [
    // Two readings on each day; Jan 3 only has the morning one.
    { date: "2025-01-01", intensity: 8 }, { date: "2025-01-01", intensity: 8 },
    { date: "2025-01-02", intensity: 2 }, { date: "2025-01-02", intensity: 2 },
    { date: "2025-01-03", intensity: 8 },
    { date: "2025-01-04", intensity: 4 }, { date: "2025-01-04", intensity: 4 },
];

renderHeatmapTracker(this.container, {
    entries,
    year: 2025,
    heatmapTitle: "Summed (the default)",
    heatmapSubtitle: "Jan 3 scores 8 — indistinguishable from Jan 4, rated 4 twice.",
    intensityConfig: { scaleStart: 1, scaleEnd: 20 },
});
```

```dataviewjs
const entries = [
    { date: "2025-01-01", intensity: 8 }, { date: "2025-01-01", intensity: 8 },
    { date: "2025-01-02", intensity: 2 }, { date: "2025-01-02", intensity: 2 },
    { date: "2025-01-03", intensity: 8 },
    { date: "2025-01-04", intensity: 4 }, { date: "2025-01-04", intensity: 4 },
];

renderHeatmapTracker(this.container, {
    entries,
    year: 2025,
    heatmapTitle: "Averaged",
    heatmapSubtitle: "Jan 3 scores 8, like the other day rated 8.",
    intensityConfig: { scaleStart: 1, scaleEnd: 10, aggregation: "average" },
});
```

The same applies to several tracked properties on one note — averaging divides
by how many of them the note actually sets:

```heatmap-tracker
heatmapTitle: Average minutes per activity
property:
  - exercise
  - learning
intensityConfig:
  aggregation: average
```

Keep the default `sum` for anything cumulative (total minutes, pages, steps).
