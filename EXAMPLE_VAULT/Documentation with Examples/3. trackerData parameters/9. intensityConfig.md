# intensityConfig

> 📖 Full parameter reference: [README → `intensityConfig`](https://github.com/mokkiebear/heatmap-tracker#intensityconfig)

## Example

```dataviewjs
const trackerData = {
    entries: [
        { date: "2025-01-01", intensity: 10 },
        { date: "2025-01-02", intensity: 1 },
    ],
    intensityConfig: {
        scaleStart: 1,
        scaleEnd: 10,
        excludeFalsy: true,
        defaultIntensity: 5,
        showOutOfRange: true
    },
    heatmapTitle: "Heatmap with intensityConfig",
}

renderHeatmapTracker(this.container, trackerData);
```

## aggregation: average

A day whose value comes from several numbers is scored on their sum by default.
For ratings that penalises a day you only logged once — a morning-only `6` out
of 10 looks like 6 out of a possible 20. `aggregation: average` scores the day
on the values it actually has, so a lone `6` is a `6`.

```heatmap-tracker
heatmapTitle: Hunger (averaged)
property:
  - hunger-morning
  - hunger-evening
intensityConfig:
  aggregation: average
  scaleStart: 1
  scaleEnd: 10
```

Keep the default `sum` for anything cumulative (minutes, pages, steps).
