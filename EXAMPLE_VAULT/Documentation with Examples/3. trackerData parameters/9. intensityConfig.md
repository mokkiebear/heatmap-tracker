# intensityConfig

> 📖 Full parameter reference: [README → `intensityConfig`](https://github.com/mokkiebear/heatmap-tracker#intensityconfig)

## Example

```dataviewjs
const trackerData = {
    entries: [
        { date: "2025-01-01", intensity: 10 },
        { date: "2025-01-02", intensity: 1 },
    ],
    intensityConfig: {
        scaleStart: 1,
        scaleEnd: 10,
        excludeFalsy: true,
        defaultIntensity: 5,
        showOutOfRange: true
    },
    heatmapTitle: "Heatmap with intensityConfig",
}

renderHeatmapTracker(this.container, trackerData);
```

## aggregation: average

A day whose value comes from several numbers is scored on their sum by default.
That's right for totals, but wrong for ratings: with two readings a day, a day
you only logged once scores half of what it should.

Both heatmaps below hold the same readings on the same 1–10 scale — a rating
logged twice a day, except Jan 3, which only got a morning entry of `8`.
`aggregation` is the only thing that differs between them.

Summed, Jan 3 lands on the same shade as Jan 4, which was rated a mediocre `4`
twice: two mediocre sessions add up to one good one. Averaged, Jan 3 matches
Jan 1, the other genuine `8` — only the readings that exist count towards the
divisor.

```dataviewjs
const entries = [
    // Two readings on each day; Jan 3 only has the morning one.
    { date: "2025-01-01", intensity: 8 }, { date: "2025-01-01", intensity: 8 },
    { date: "2025-01-02", intensity: 2 }, { date: "2025-01-02", intensity: 2 },
    { date: "2025-01-03", intensity: 8 },
    { date: "2025-01-04", intensity: 4 }, { date: "2025-01-04", intensity: 4 },
];

renderHeatmapTracker(this.container, {
    entries,
    year: 2025,
    heatmapTitle: "Summed (the default)",
    heatmapSubtitle: "Jan 3 (one 8) ties with Jan 4 (two 4s).",
    intensityConfig: { scaleStart: 1, scaleEnd: 10 },
});
```

```dataviewjs
const entries = [
    { date: "2025-01-01", intensity: 8 }, { date: "2025-01-01", intensity: 8 },
    { date: "2025-01-02", intensity: 2 }, { date: "2025-01-02", intensity: 2 },
    { date: "2025-01-03", intensity: 8 },
    { date: "2025-01-04", intensity: 4 }, { date: "2025-01-04", intensity: 4 },
];

renderHeatmapTracker(this.container, {
    entries,
    year: 2025,
    heatmapTitle: "Averaged",
    heatmapSubtitle: "Jan 3 now matches Jan 1, and outranks Jan 4.",
    intensityConfig: { scaleStart: 1, scaleEnd: 10, aggregation: "average" },
});
```

The same applies to several tracked properties on one note. This vault's daily
notes log `exercise` every day but `learning` only on about two days in three,
so the two heatmaps below differ on every day that's missing its `learning`
entry — summed, those days look like slacking; averaged, they're scored on the
session that did happen:

```heatmap-tracker
heatmapTitle: Minutes per day (summed — the default)
property:
  - exercise
  - learning
```

```heatmap-tracker
heatmapTitle: Average minutes per logged activity
property:
  - exercise
  - learning
intensityConfig:
  aggregation: average
```

Keep the default `sum` for anything cumulative (total minutes, pages, steps).
